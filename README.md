#### **#Personal Finance Budget Dashboard**

### **---**

##### **## Overview**

###### An interactive finance dashboard built using Microsoft Excel to track income, expenses, savings, and budget performance.

### **---**

#### **## Features**

###### \- Budget vs Actual Analysis

###### \- KPI Tracking

###### \- Interactive Year \& Period Filters

###### \- Expense Categorization

###### \- Savings Analysis

###### \- Dynamic Charts and Visualizations

### **---**

#### **## Tools \& Functions Used**

###### \- Microsoft Excel

###### \- Conditional Formatting

###### \- SUMIFS

###### \- IF Functions

###### \- Data Validation

###### \- Interactive Controls

### **---**

#### **## Dashboard Components**

#### **### Income Tracking**

###### Tracks multiple income sources and compares against budget targets.

##### 

#### **### Expense Tracking**

###### Analyzes spending across categories such as groceries, housing, utilities, and transport.

### 

#### **### Savings Analysis**

###### Monitors investment and savings allocation.

### 

#### **### Interactive Dashboard**

###### Allows dynamic filtering using year and period selectors.

### **---**

#### **## Key Insights**

###### \- Identified highest expense categories

###### \- Analyzed savings rate trends

###### \- Compared planned budget vs actual spending

###### \- Improved financial tracking visibility
